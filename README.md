
# E-commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data to understand sales performance, revenue, profit, product categories, and order status.

## Objectives
- Analyze total revenue and profit.
- Identify top-performing product categories.
- Analyze order status.
- Identify sales trends.
- Generate business insights using data.

## Dataset
The dataset contains e-commerce sales information, including:
- Order ID
- Category
- Price
- Quantity
- Discount
- Revenue
- Cost
- Profit
- Order Status
- City
- Date
